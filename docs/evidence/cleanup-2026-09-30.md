# Cleanup of the shell-script migration (2026-09-30)

Packages `mqtt-metrics-0.1.0-r8` and `luci-app-mqtt-metrics-0.1.0-r7`
(ADR-0007), installed on both routers on 2026-10-01 (below).

## Checks

- `E2E=1 tools/check.sh`: fmt, clippy with and without TLS, 96 unit tests,
  the topic compatibility test, 5 client and 4 TLS tests, Node tests, the
  LuCI view tests on the stand-in and on the real LuCI code, the end-to-end
  smoke test (5 scenarios). All pass.
- SDK build: the daemon package depends on `ca-bundle`, `libc`, `libgcc1`,
  `ubus`, `uci`; both extra packages are installed on the test routers.

## Dry run on the test routers

The daemon from the r8 package ran `--check-config` and `--dump` on both
routers next to the installed r7 (nothing is sent; the copy in `/tmp` was
removed afterwards).

| Router | Configuration | r7 dump | r8 dump | Difference |
| --- | --- | --- | --- | --- |
| Primary 10.0.77.1 | valid | 66 messages | 50 | 16 fewer clears |
| Secondary 10.0.77.2 (`cleanup_legacy '1'` still set) | valid | 60 | 38 | 22 fewer clears |

Every published value is the same. The dry run starts from an empty set of
owned topics, and r7 added the script's topics to it and cleared the
impossible ones; r8 no longer does. The running daemon works from
`state.json`, and the capture of the broker after the r7 installation holds
none of those topics on either router, so nothing changes in production.

## Removal of the script and installation (2026-10-01)

Confirmed by the owner in chat for all three steps: push, removal of the
script, installation; secondary first.

`tools/retained.sh` (new) reads the retained topics with the broker settings
of `/etc/config/mqtt-metrics` and the password from `/etc/mqtt-metrics/secret`
through a temporary 0600 options file, so the password is on no command line.
Before the script was removed it returned the same topics as the old check
that took the credentials from the script (39 on the secondary, 51 on the
primary).

| | Secondary 10.0.77.2 | Primary 10.0.77.1 |
| --- | --- | --- |
| Script and marker | removed; no cron line, no `rc.local` reference, no running process | the same |
| `ubus` objects before / after | 50 / 50 | 57 / 57 |
| LuCI `/ubus`, rpcd object | ok, present (no `legacy` or `import_legacy` method) | ok, present |
| Retained topics before / after | 17 states, 22 configs / the same | 26 states, 25 configs / the same |
| Changed | `system/uptime` only; no discovery config changed | the same |
| After the first tick | connected, 0 reconnects, 0 publish errors, no warning | connected, 0 reconnects, 0 publish errors, no warning |
| Other | RSS 2.5 MB | RSS 2.5 MB; HA role MASTER, state HEALTHY |

`/etc/config/mqtt-metrics.apk-new` (the packaged default) was removed again
on both routers. `state.json` keeps its old `legacy_seeded` field until the
set of owned topics changes; it is ignored.

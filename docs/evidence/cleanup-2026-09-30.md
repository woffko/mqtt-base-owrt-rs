## Dry run on the test routers

The daemon from the r8 package ran `--check-config` and `--dump` on both
routers next to the installed r7 (nothing is sent; the copy in `/tmp` was
removed afterwards).

| Router | Configuration | r7 dump | r8 dump | Difference |
| --- | --- | --- | --- | --- |
| Primary 10.0.77.1 | valid | 66 messages | 50 | 16 fewer clears |
| Secondary 10.0.77.2 (`cleanup_legacy '1'` still set) | valid | 60 | 38 | 22 fewer clears |

Every published value is the same. The dry run starts from an empty set of
owned topics, and r7 added the script's topics to it and cleared the
impossible ones; r8 no longer does. The running daemon works from
`state.json`, and the capture of the broker after the r7 installation holds
none of those topics on either router, so nothing changes in production.
